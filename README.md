Module 8 – Data Lookup with Dictionaries & Basic Aggregation
This repository contains my work for Module 8 of the Python for Data Analysis course.
Assignment Overview
This assignment simulates a customer management system for a fictional company called GlobalTech Solutions. The goal is to store, retrieve, and analyze customer and project data using Python dictionaries.
Files Included

module08-assignment.py – Main Python script with all completed tasks

What I Practiced

Creating and nesting dictionaries to represent real-world data (customers, projects, services)
Accessing, updating, and deleting dictionary entries using keys and .get()
Iterating over dictionaries with loops to display and process data
Writing dictionary comprehensions to filter and transform data
Building functions for customer validation, budget analysis, and service recommendations
Performing financial aggregations (total hours, total budget, average budget, min/max)
Categorizing data using conditional expressions inside comprehensions
